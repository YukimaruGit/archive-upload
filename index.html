アーカイブ自動投稿

Twitchの配信アーカイブを、配信者本人のYouTubeチャンネルへ投稿するための、個人用のWindowsツールです。

できること

  • 運営者本人のTwitch配信が終わったあと、そのアーカイブを本人のYouTubeチャンネルに投稿します。
  • 投稿する動画に、タイトル、説明欄、サムネイルを設定します。
  • すでに投稿した動画を確認し、同じ配信を二重に投稿しないようにします。

使う人

運営者本人だけが使います。一般には配布していません。

YouTubeの情報の使い方

このツールはYouTube API Servicesを利用しています。動画を投稿するための権限と、自分のチャンネルの動画一覧を読むための権限だけを使います。詳しくはプライバシーポリシーをご覧ください。
