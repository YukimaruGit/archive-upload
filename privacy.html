プライバシーポリシー

「アーカイブ自動投稿」（以下、本ツール）が、Googleアカウントの情報をどう扱うかを説明します。

1. 本ツールについて

本ツールは、運営者本人のTwitch配信アーカイブを、運営者本人のYouTubeチャンネルへ投稿するための個人用ツールです。運営者本人のパソコンの中だけで動き、一般には配布していません。本ツールはYouTube API Servicesを利用しています。

2. 利用する情報

  • youtube.upload：動画の投稿と、サムネイルの設定に使います。
  • youtube.readonly：投稿先のチャンネルが正しいかの確認と、投稿済みの動画（タイトル、説明欄、投稿日時、長さ、公開状態など）の確認に使います。二重投稿を防ぎ、投稿が終わったかを確かめるためです。

3. 情報の保存

  • Googleから受け取った認証情報は、運営者のパソコンの中に、Windowsの機能で暗号化して保存します。
  • 投稿の記録（動画のID、タイトル、投稿日時、公開状態など）は、運営者のパソコンの中に保存します。
  • 外部のサーバーには保存しません。

4. 情報の共有

Googleから受け取った情報を、第三者に提供、販売、共有することはありません。広告や、AIの学習にも使いません。通信先は、動画の投稿に必要なGoogleのサービスです。動画の元になるアーカイブは、Twitchから受け取ります。

5. 利用の停止と削除

Googleアカウントの設定から、いつでも本ツールの許可を取り消せます。パソコンに保存した認証情報と記録は、ファイルを削除することで消せます。

6. 関連する規約

  • YouTube利用規約
  • Googleプライバシーポリシー
  • Google API Services User Data Policy（本ツールは、Limited Useの要件を含めてこれに従います）

7. お問い合わせ

運営者のTwitchチャンネルからご連絡ください。
